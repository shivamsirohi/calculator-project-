# 🧮 Python Calculator & Table Generator

A simple and beginner-friendly Python CLI application to generate multiplication tables, perform basic arithmetic, and calculate percentages!

---

## ✨ Features

- **📊 Table Generator:** Generate complete multiplication tables for any given number using loops.
- **💯 Percentage Calculator:** Easily calculate percentages for marks or custom values.
- **➕ Basic Arithmetic Operations:**
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)

---
